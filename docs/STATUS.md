- 创建租户管理员账号时，在一个事务中创建 tenant、user 和 membership。

## 已完成任务：M2-D

- `POST /api/v1/conversations/{conversation_id}/messages/stream` 在持久化用户消息和生成中回复后，以 `started`、`delta`、`completed` 或 `cancelled` SSE 事件发送确定性回复。
- 分段写入、停止和完成都通过数据库状态条件更新；`completed` 与 `cancelled` 是终态，不相互覆盖。竞争结果以数据库提交为准；停止前已提交但尚未送达的分段可能仍在网络缓冲中，停止后不再追加持久化内容。
