- `GET /health/live` 用于进程存活检查。
- `GET /health/ready` 实际探测 PostgreSQL、Redis 和 Qdrant，并在必要依赖不可用时返回 `503`。
- 后端 Ruff 检查和 3 个 Pytest 测试通过。

- Web 和 API 分别使用宿主机端口 `5173` 与 `8000`；三个数据服务默认只在 Compose 内部网络可访问。

## 已完成任务：M2-A

目标是在不加入前端登录页面和对话功能的前提下，建立可信的最小身份基础：

- 创建租户管理员账号时，在一个事务中创建 tenant、user 和 membership。
- 使用密码登录并获得有过期时间的访问令牌。
- 使用访问令牌读取当前用户、租户和角色。
- 每次访问受保护接口时重新检查用户及成员关系是否仍然启用，使停用操作可以撤销旧令牌的权限。
- 使用 Alembic 管理数据库结构，并覆盖关键正常路径与失败路径测试。

详细范围、非范围、验收映射和执行顺序见 [M2 里程碑](milestones/M2.md)。
